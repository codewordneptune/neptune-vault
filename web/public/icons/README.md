# Web app icons

Rasterised from the brand mark in `public/favicon.svg` (the same paths as
useneptune.org's logo) on a navy gradient, `#22344d` at the top to
`#0d131c` at the bottom, with a faint blue glow at the top left:
`icon-192.png` and `icon-512.png` are rounded tiles for the `any` purpose,
and `icon-maskable-512.png` is full bleed with the mark inside the safe
zone for Android's adaptive icons. `icon-192.png` is also the Apple touch
icon (`web/index.html`).

To render them again (the originals were drawn onto a browser canvas and
saved as PNG): the mark in `#3a8bf3`, centred, about 57% of the width on
the rounded tiles and 46% on the maskable one; the tiles' corners about 22%
of the width.

The Android app's launcher icon is made from these
(`shells/tauri/icons/README.md`): after a change here, make it again.
